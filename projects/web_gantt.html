Internal Web Platform — Test Data and Performance Analytics

During project planning and coordination, I identified a recurring issue: most employees did not have access to licensed Gantt diagram software, which created communication bottlenecks and unnecessary dependencies.

To solve this, I designed and developed a web-based Gantt diagram viewer, accessible to anyone connected to the company’s internal network.

The tool allows users to view only the diagrams relevant to their role or department, improving transparency while keeping information structured.

Technical details

The application was developed as a full-stack solution:

  • Backend: Python + FastAPI
  • Frontend: HTML, CSS, JavaScript
  • Access control based on IP validation
  • Server: Ubuntu Server running on a local virtual machine

By hosting the service on a VM running on my desktop workstation, the tool avoids using the corporate server while leveraging otherwise underutilized hardware resources.

Impact

  • Elimination of license-related limitations
  • Reduced communication friction between departments
  • Improved project visibility and alignment
  • Better use of existing IT resources
