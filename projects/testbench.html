Hydraulic Pump Test Bench Software

Python-based real-time data acquisition and visualization system for hydraulic pump testing bench, coupled with PID control systems for Flowrate and Voltage automatic regulation.

Overview

When I took responsibility for the R&D laboratory, the existing infrastructure was outdated in terms of data acquisition, automation, processing, visualization, and digital communication. Testing procedures were largely manual, slow, and difficult to compare across different products and conditions.

The goal of this project was to transform the laboratory into a modern, fully automated, data-driven R&D environment, capable of supporting both new product development and continuous improvement of existing hydraulic pumps.

This project became the central technical backbone of R&D activities at the company.

Scope and responsibilities

I was responsible for the complete technical design and implementation of the system, covering:

  • Automation of hydraulic pump test benches
  • Sensor integration and instrumentation
  • Data acquisition and processing
  • Closed-loop control systems
  • Software development (control, visualization, and analysis)
  • Digital organization and communication of test results
  • All changes and improvements to test procedures and product validation passed through this system.

Technical implementation

At the core of the project is a custom-developed control and acquisition platform, designed and programmed from scratch.

The system integrates multiple sensors (pressure, flow, electrical variables) with the electrical and mechanical components of the test bench. Data is acquired in real time and processed by software developed in Python and C++, depending on performance requirements.

Closed-loop control plays a central role. I implemented multiple PID controllers, including:

  • Input voltage control for test stability
  • Fully automated control of the gate valve, allowing test sequences to run without manual intervention

Test protocols can be executed automatically, ensuring repeatability, safety, and consistency across experiments.

GUI

To operate the system, I developed a custom GUI from scratch, which acts as the central interface for the entire laboratory.

Through the GUI, users can:

  • Monitor all sensor data in real time
  • Control actuators and PLC-driven elements
  • Launch automated test sequences
  • Visualize performance curves and key metrics
  • Compare live test data against previously acquired datasets

This interface replaced fragmented tools and manual procedures, centralizing all laboratory operations in a single, intuitive platform.

Data visualization and decision-making

Beyond basic monitoring, I developed tools to visualize and compare results instantly, both in real time and against historical data.

This made it possible to:

  • Identify performance trends immediately
  • Detect anomalies during tests instead of post-processing
  • Make faster decisions at both the technical and managerial level

The shift from delayed analysis to near-instant feedback significantly changed how R&D decisions were made within the company.

Impact and results

The combined effect of automation, software integration, and data visualization led to measurable improvements:

  • Testing time reduced by more than 500%
  • Immediate availability of clean, structured data
  • Increased test repeatability and reliability
  • Faster iteration cycles in product development
  • Stronger alignment between R&D, production, and management

This project became a reference point for how future testing and development work is structured at Bombas Rowa.
