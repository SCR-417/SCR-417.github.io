Hydraulic Pump Test Bench Software

Python-based real-time data acquisition and visualization system for hydraulic pump testing bench, coupled with PID control systems for Flowrate and Voltage automatic regulation.

Overview

When I took responsibility for the R&D laboratory, the existing infrastructure was outdated in terms of data acquisition, automation, processing, visualization, and digital communication. Testing procedures were largely manual, slow, and difficult to compare across different products and conditions.

The goal of this project was to transform the laboratory into a modern, fully automated, data-driven R&D environment, capable of supporting both new product development and continuous improvement of existing hydraulic pumps.

This project became the central technical backbone of R&D activities at the company.

Scope and responsibilities

I was responsible for the complete technical design and implementation of the system, covering:

  • Automation of hydraulic pump test benches
  • Sensor integration and instrumentation
  • Data acquisition and processing
  • Closed-loop control systems
  • Software development (control, visualization, and analysis)
  • Digital organization and communication of test results
  • All changes and improvements to test procedures and product validation passed through this system.

System Architecture

The system is composed of pressure, flow, and temperature, rotational speed sensors, a PLC-based control unit, and a Python application for monitoring.

Special care was taken to ensure measurement repeatability and automated report generation.
