Internal Web Platform — Test Data and Performance Analytics

As test automation increased, the volume of empirical data grew rapidly. I developed a dedicated web platform to ensure that this data was not only stored, but also easily accessible, comparable, and actionable.

The platform collects and classifies data from all tests and stores it in a structured database, allowing authorized users to explore pump performance across different models and operating conditions.

Technical architecture

I was responsible for the complete technical design and implementation of the system, covering:

  • Backend: Python + FastAPI
  • Database: PostgreSQL
  • Frontend: Custom HTML/CSS/JavaScript interface
  • Server: Ubuntu Server running on a local virtual machine

Users can visualize performance data in real time, compare datasets, and automatically generate Excel files with selected comparisons for sharing and reporting purposes.

Value generated

  • Centralized, structured empirical knowledge base
  • Faster performance comparisons
  • Improved traceability of test results
  • Support for data-driven product decisions
